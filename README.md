# 🏮 Китай-Квест

Веб-приложение для совместной поездки в Китай: ежедневные задания, очки и общий лидерборд. Заходишь с телефона, вводишь имя и PIN — и ты в игре.

## Игры

1. **Фото-миссия дня** — одно общее задание на всех, одна попытка загрузки, вечером голосование за лучшее фото (за себя нельзя, голос можно менять). Сдал фото: **+5**, каждый голос за твоё фото: **+7**.
2. **Фотоохота** — каждый день по 3 стёбных и абстрактных цели («собака в одежде», «охранник, охраняющий пустоту»…). Это поиск, а не конкурс фотографии: нашёл, сфоткал, доказал — каждая цель **+8**. Список дня фиксируется утром, пул целей пополняется в админке.
3. **Цепочка чисел** — общий счётчик с 1: ищи число вокруг, фоткай первым. Число N: **+N** (максимум +30). Нашедший прошлое число пропускает ход.
4. **Бинго дня** — личная карточка 5×5 из того, что реально высматривается на улице: Шанхай («башня Жемчужина», «бельё на шесте», «человек в пижаме»), уличный Китай («тайцзи в парке», «скутер втроём», «каллиграфия водой»), еда («бамбуковая пароварка», «вонючий тофу»), технологии («робот-официант», «оплата лицом»), игры и аниме («автомат-хватайка», «гашапон-автомат»), туристы («флажок экскурсовода», «торг на калькуляторе»). Увидел — отмечай клетку; подстраивать самому не считается; отметку можно сбросить, каждое изменение — через подтверждение. Клетка: **+2**, линия (5 в ряд): **+10**, вся карта: **+40**. Пул слов пополняется через вкладку «Админ» (видна только админу); уже розданные карточки при правке пула не меняются.

5. **Фотофраза** — раунд, а не день. Каждый сдаёт по два слова: прилагательное и существительное (чужие слова скрыты до старта). На старте слова тасуются, и каждому достаётся чужая пара — «беременный огнетушитель», «грустный дракон» — её надо сфотографировать в реальной жизни, одна попытка. Слова: **+3**, фото по фразе: **+12**. Раунд закрывается сам, когда все сдали фото, либо досрочно любым игроком; после этого любой открывает следующую игру. Незапущенную игру (этап сбора слов) закрывает только админ — чтобы начать заново в другой день, не доигрывая брошенную. Своё слово не достаётся никому. Ничего не удаляется: слова и фото привязаны к своей игре, прошлые игры лежат в блоке «Прошлые игры» — фраза показывается вместе со своим фото.

Контент дня (миссия, цели охоты, карточки бинго) выбирается детерминированно из FNV-1a-хеша даты. Игровой день — по времени Китая (`TZ_OFFSET_HOURS=8`). Очки считаются на лету из исходных таблиц.

## Локальный запуск

```bash
# бэкенд (порт 3000)
cd server && npm install && npm run dev

# фронтенд (порт 5173, прокси /api и /uploads на :3000)
cd client && npm install && npm run dev
```

Продакшен-сборка без Docker:

```bash
cd client && npm install && npm run build
cd ../server && npm install && JWT_SECRET=секрет NODE_ENV=production npm start
# Express сам раздаёт client/dist на :3000
```

## Docker

```bash
cp .env.example .env        # и впиши настоящий JWT_SECRET
docker compose up -d --build
```

БД и фото живут в volume `quest-data` (`/app/data`).

## Деплой

### Railway

```bash
npm i -g @railway/cli
railway login
railway init                # создать проект
railway volume add --mount-path /app/data
railway variables --set "JWT_SECRET=$(openssl rand -hex 32)"
railway up                  # соберёт Dockerfile и задеплоит
railway domain              # выдать публичный URL
```

### Fly.io

```bash
brew install flyctl
fly auth login
fly launch --no-deploy      # определит Dockerfile; internal_port = 3000
fly volumes create quest_data --size 1
# в fly.toml добавь:
#   [mounts]
#     source = "quest_data"
#     destination = "/app/data"
fly secrets set JWT_SECRET=$(openssl rand -hex 32)
fly deploy
```

Важно: приложение хранит состояние в SQLite — запускать строго в **один инстанс** (Fly: `fly scale count 1`).

## API

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/join` | `{name, pin}` — регистрация или вход |
| GET | `/api/day/today` | сводка дня (миссия, мои статусы по фото) |
| POST | `/api/day/vote-photo` | голос за фото `{targetUserId}` |
| POST | `/api/photos` | загрузка фото дня (multipart, поле `photo`) |
| GET | `/api/photos/today` | галерея дня с голосами |
| GET/POST | `/api/chain` | состояние цепочки / загрузка фото числа |
| GET | `/api/hunt` | цели охоты дня с находками |
| POST | `/api/hunt` | фото-доказательство (multipart: `photo`, `item`) |
| GET | `/api/bingo` | карточка бинго дня |
| POST | `/api/bingo/mark` | отметить/сбросить клетку `{cell, marked}` |
| GET | `/api/phrase` | состояние раунда фотофразы |
| POST | `/api/phrase/round` | открыть новый раунд (когда прошлый доигран) |
| POST | `/api/phrase/words` | сдать/поменять свои слова `{adjective, noun}` |
| POST | `/api/phrase/start` | перемешать слова и раздать фразы |
| POST | `/api/phrase/photo` | фото по своей фразе (multipart, поле `photo`) |
| POST | `/api/phrase/finish` | закрыть игру досрочно (на этапе сбора слов — только админ) |
| GET | `/api/phrase/history` | прошлые игры: фразы вместе с фото |
| GET/PUT | `/api/admin/config` | конфиг игр (только админ) |
| GET | `/api/leaderboard` | лидерборд |
| GET | `/api/players` | список игроков |
| GET | `/api/me` | кто я |
| GET | `/api/health` | без авторизации |

Всё, кроме `join` и `health`, — под Bearer JWT.

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Что делает |
|---|---|---|---|
| `JWT_SECRET` | да (в проде) | — | подпись токенов |
| `TZ_OFFSET_HOURS` | нет | `8` | смещение игрового дня |
| `PORT` | нет | `3000` | порт сервера |
| `DATA_DIR` | нет | `./data` | путь к БД и фото |

## Бэклог

Асинхронный коднеймс, бинго путешественника 3×3, «тайное поручение», цитата дня, «угадай цену», шпион-фотограф, аукцион шагов; WebSocket вместо поллинга, Web Push «тебя подозревают», админка для своих пулов заданий.
